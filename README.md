# My dotfiles

linker.sh contains all symlink commands. Run it to link everything. It's idempotent, so re-running is safe. Required software must be installed manually.

## Terminal environment

- Ghostty, Zsh, Powerlevel10k, MesloLGS NF
- zsh-autosuggestions, zsh-syntax-highlighting
- zoxide, fzf, eza, atuin
- tmux, neovim, yazi, lazygit, delta

## Additional software

- Homebrew, Mas (macOS)
- Nix, nh, Nala (Debian), Paru (Arch)
- Docker
- AeroSpace (macOS)
