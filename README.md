# My dotfiles

linker.sh contains all symlink commands. Run it to link everything. It's idempotent, so re-running is safe.

plugins.zsh sources plugins from Nix store paths and requires the Nix package manager. Use downloader.sh to install most dependencies. Some will still need to be installed manually.

## Terminal environment

- Zsh
- Ghostty
- Powerlevel10k, MesloLGS NF
- zsh-autosuggestions, zsh-syntax-highlighting
- zoxide, fzf, eza, atuin
- tmux, neovim, yazi, lazygit, delta

## Additional software

- Nix package manager
- Homebrew, Mas (macOS)
- Nala (Debian)
- Paru (Arch)
- Docker
- AeroSpace (macOS)
