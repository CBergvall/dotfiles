# My zshrc configurations for different devices

### Linking command for laptop (Macbook):

```
ln -sf ~/dotfiles/shell/zshrc/laptop/.zshrc ~/.zshrc
```

### linking command for desktop (Windows WSL/Linux):

```
ln -sf ~/dotfiles/shell/zshrc/desktop/.zshrc ~/.zshrc
```

### linking command for mobile (Termux):

```
ln -sf ~/dotfiles/shell/zshrc/mobile/.zshrc ~/.zshrc
```
